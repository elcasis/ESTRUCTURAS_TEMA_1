¿Clase, Objeto, Atributo o Método?

Aprende a diferenciar los 4 conceptos clave de la Programación Orientada a Objetos en Java desde tu móvil.

📐 1. CLASE (El Molde General) class

Es el plano, plantilla o categoría general que define cómo serán los objetos de ese tipo.

Ejemplos: «Perro», «Coche», «Smartphone», «CuentaBancaria».

🧸 2. OBJETO (El Ejemplar Concreto) new

Es un individuo único y concreto creado a partir de la clase (tiene nombre propio o identidad).

Ejemplos: «Mi perro Toby», «El Seat Ibiza matrícula 4589-KLM», «La alumna Laura».

🏷️ 3. ATRIBUTO (La Característica / Dato) variable

Es una cualidad, propiedad o dato que describe el estado del objeto.

Ejemplos: «El color del perro», «La velocidad máxima», «El saldo actual».

⚡ 4. MÉTODO (La Acción / Comportamiento) accion()

Es un verbo o acción que el objeto sabe realizar. En Java siempre lleva paréntesis ().

Ejemplos: «Ladrar y correr», «Acelerar y frenar», «Enviar un mensaje».
